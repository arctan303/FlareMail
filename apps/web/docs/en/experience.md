# Online experience

Open the inbox directly without signing in. All messages, addresses, members, contacts and settings are sample data.

## What to try

- Read messages, expand recipient details, copy verification codes and save senders as contacts.
- Search, paginate, sort by time, filter all/unread/starred/attachments, and use batch actions.
- Compose, reply, forward and attach files; read simulated sends in Sent.
- Save, search, open and delete drafts, and minimize the compose window.
- Manage contacts and groups, and use the top selector to view all mailboxes or a single address.
- Explore personal settings, all six administrator sections, branding and the sign-in preview.
- Switch Chinese/English and light/dark appearance; try mobile layouts and shortcuts.

## Data and limits

Mail, drafts, attachments and settings stay in the current page's memory. Refreshing restores the initial samples. Appearance preferences may persist. Each fresh visit uses the browser’s preferred language: all Chinese variants use Simplified Chinese, and other languages use English. You can also switch language in personal settings.

Simulated sends never deliver mail. Personal and administrator settings are for viewing; only language can be changed. Configuration saves, password confirmation and token generation are not simulated. Google authorization, real database maintenance and external delivery require your own mailbox deployment.

Primary-address migration requires your own mailbox instance. External mail images are not loaded in the experience; locally uploaded images and attachments can be previewed.

Use sample information when exploring.
