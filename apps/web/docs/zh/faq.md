# 常见问题

## 体验站会投递真实邮件吗？

不会。体验站是纯静态前端，使用示例数据，不接入真实 Worker 或邮箱服务。刷新恢复初始数据；设置主要供查看。

## 可以公开注册吗？

不可以。管理员创建受邀成员并交付初始登录信息；Google 登录也不会自动注册邮箱。[管理员配置](/docs/zh/administration)

## 可以用 Outlook 或手机邮件客户端连接吗？

目前通过 Web 界面或 CLI API 使用，不提供 IMAP、POP3 或 SMTP 客户端接入。PWA 可安装到设备，但不代表完整离线邮箱或跨设备草稿同步。

## 登记了域名，为什么还不能收发？

登记只完成应用配置。收信需要域名 DNS 与 Email Routing 指向 Worker；发信需验证域名、配置服务商凭据。用外部邮箱测试，检查垃圾箱。[收信](/docs/zh/receiving) · [发信](/docs/zh/sending)

## 本地为什么收不到公网邮件？

本地 Worker 没有公网收信路由。开发时可使用[本地模拟邮件事件](/docs/zh/getting-started)，真实收信需部署。

## 为什么 Google 登录失败？

先确认管理员已配置 Google 凭据、准确回调地址及允许的用户。成员需先用密码登录并绑定自己的 Google 账号，之后才能 Google 登录。[配置步骤](/docs/zh/administration)

## 附件需要公网 R2 域名吗？

不需要。附件经 Worker 鉴权访问，R2 桶保持私有；R2 可选，无绑定时使用 KV。切换存储不会自动搬运旧附件。[配置与存储](/docs/zh/configuration)

## 更新提示数据库待升级怎么办？

保留现有资源，登录「系统设置 → 系统维护」检查补丁。升级前先备份；恢复数据库不能自动恢复附件对象。[更新与恢复](/docs/zh/updates)

## 为什么部分文字没有随语言切换？

个人设置可选择简体中文或英文；自定义站点品牌文字和邮件内容不会自动翻译。体验站每次打开按浏览器语言初始化，中文统一简体，其余语言使用英文。
