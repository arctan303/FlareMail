# 使用指南

## 阅读与整理

收件箱在页面可见且联网时默认每 30 秒检查新邮件，切回页面或恢复网络时立即检查。检测到新邮件后在后台更新当前页，保留页码和滚动位置；勾选邮件或操作菜单期间延后更新。隐藏页面会暂停检查，手动刷新按钮仍可使用。

左侧选择收件箱、已发送或草稿。顶部「全部邮箱」汇总自己的主邮箱和子邮箱；选择具体地址只显示该邮箱的邮件，并回到第一页。筛选可以与搜索、未读、星标、含附件及时间排序配合，不改变邮箱的接收策略或登录身份。

收件箱、已发送和星标列表每个会话只显示一行，显示邮件数量，每页最多 50 个会话。会话中有未读来信时整行加粗。使用顶部箭头翻页，返回列表保留筛选与分页。列表上的标记、星标和删除作用于当前文件夹及邮箱筛选范围内的会话成员；搜索、未读或附件条件不会把操作缩成仅匹配的几封。草稿及管理员邮件列表仍逐封展示。

打开会话后，阅读页会将同一回复链中的收信与发信按时间排列，最新邮件在底部。默认展开最新邮件，其余显示摘要；可以逐封展开、全部展开或加载更早邮件。成功加载后，整个会话已有的来信统一标为已读，包括折叠及尚未加载的历史页；标记失败可重试，新来信仍会使会话显示未读。阅读页每封邮件的附件、回复、星标、删除和手动标记只作用于该封邮件。

会话同时依据回复关联信息和主题：开头重复的 `Re:`、`Re[n]:`、`回复：`、`回覆：`、`答复：` 不影响归组，真正修改主题会另起会话。独立发送但主题相同的邮件不会仅因同名合并；`Fwd:` 等转发前缀保留。缺少关联信息的历史邮件可能仍单独显示。若只找到部分来往，页面会提示。阅读查询最多检查当前用户最近 5000 封可访问邮件及当前邮件，单条会话最多展示 200 封。列表聚合与会话操作最多支持每用户 10000 封有效邮件，超限会明确提示，不返回截断后的错误总数。

列表与会话顶部显示整理回复前缀后的主题；展开历史邮件不会重复大标题。每封原始主题可在收件信息详情中查看，回复仍使用对应邮件的主题。改题只影响会话归类，原始邮件主题、回复关联头和历史正文均保留。

## 写信、回复与附件

点击「写新邮件」，选择发件地址并填写收件人、主题与正文。可从联系人选择地址，或手动输入。回复与转发在邮件阅读页底部。

回复收到的邮件时，优先使用发件人指定的「回复地址」（Reply-To），没有时才使用发件地址；展开邮件头可查看和复制该地址。回复已发送邮件会继续发给原 To 收件人。历史引用可通过正文中的省略号展开，深层引用不会持续向右缩进。写信窗口也提供引用内容开关；开合只改变展示，不删减保存或发送的历史原文。

Reply-To 保存需要管理员完成数据库 325 更新。旧实例更新代码后仍可正常收发和登录，但完成数据库更新前的收件，以及更早已丢失的 Reply-To，无法自动恢复；这些邮件继续回退发件地址。

附件可以下载，图片附件支持预览。真实邮箱默认阻止外部邮件图片，按需允许加载；体验站不会加载这些外部图片。发送限制与失败排查见[发信配置](/docs/zh/sending)。

写信窗口底部可直接点击「保存草稿」，不必填写完整收件人、主题或正文；保存正文和附件后关闭窗口。关闭新邮件也会询问是否保存，已有草稿关闭时更新原稿，失败则保留编辑内容。正式邮箱草稿保存在当前浏览器的 IndexedDB，不跨设备同步；清除浏览器站点数据可能丢失草稿。体验站的草稿仅保留在当前页面，刷新即重置。

## 联系人与邮箱地址

联系人支持名称、邮箱、备注、电话和分组，可搜索或按组筛选。在邮件中展开收件详情，可把发件人保存为联系人。

个人设置可以新增别名、修改各地址的发件名称、置顶排序或删除别名；写信时选择发件地址。置顶不会改变主登录邮箱，主邮箱不能作为普通别名删除。主邮箱迁移由管理员执行，迁移后使用新邮箱与原密码重新登录。

## 偏好与接入

个人设置可以切换语言、配置转发、生成或吊销 CLI Token、绑定 Google 账号。转发目标需先通过 Cloudflare 验证，具体见[收信配置](/docs/zh/receiving)。Google 绑定需管理员先配置，见[管理员配置](/docs/zh/administration)。

修改密码会使旧凭据、会话及个人 CLI Token 失效；重新登录，并按需重新生成 Token。脚本接入见[CLI / Agent](/docs/zh/cli)。

左下角用户菜单提供主题与快捷键说明。按 C 写信，Ctrl / Command + K 搜索，? 查看快捷键。
