# 在线体验

先感受日常用起来是什么样，再决定是否部署。[打开体验邮箱](/inbox)即可开始，无需登录，邮件和账号均为示例数据。

建议先打开一个邮件会话，再试试搜索、切换邮箱地址和写信；手机上也可以直接打开。模拟发送不会投递真实邮件，刷新会恢复示例数据。

## 可以尝试

- 查看邮件、展开收件详情、复制验证码、添加联系人。
- 搜索、分页、时间排序、全部/未读/星标/含附件筛选和批量操作。
- 写信、回复、转发、上传附件；模拟发送后在已发送中阅读。
- 保存、搜索、打开和删除草稿，体验写信窗口最小化。
- 管理联系人与分组，在顶部筛选全部邮箱或单个邮箱的邮件。
- 浏览个人设置、管理员六个设置分区、品牌与登录页面预览。
- 切换中文/英文、深浅色外观与主题强调色，体验手机布局和快捷键。

## 数据与限制

邮件、草稿、附件和设置只保留在当前页面的内存中，刷新后恢复初始数据。主题偏好可保留。每次打开体验时按浏览器首选语言显示：中文统一为简体中文，其余语言使用英文；也可在个人设置中手动切换。

模拟发送不会投递邮件。个人和管理员设置仅供查看，除语言与外观主题切换外不模拟修改、保存、验密或令牌生成。Google 授权、真实数据库维护和外部收发需要部署自己的邮箱。

主邮箱迁移需要自己的邮箱实例。体验中的外部邮件图片不会加载；本地上传图片和附件可以预览。

请使用示例资料体验。
